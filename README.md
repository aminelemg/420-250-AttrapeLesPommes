# Attrape les pommes

Attrape les pommes est un jeu d'arcade en 2D réalisé avec Unity.
Le joueur déplace un panier avec les touches A et D pour attraper des pommes.
Il gagne après avoir attrapé 5 pommes.
Il perd si 3 pommes tombent au sol.
